A* Search

f(n) = g(n) + h(n) where g is cost so far and h is the heuristic estimate. Optimal when h is admissible (never overestimates). Explores far fewer nodes than Dijkstra.

How It Works

Dijkstra is A* with h=0 — it explores uniformly in all directions. BFS uses a FIFO queue and finds shortest path in unweighted graphs. DFS uses a LIFO stack — fast but not optimal. Greedy Best-First only uses h — very fast but can miss optimal paths.
