# Java Algorithmic Projects

This repository contains independent Java projects I built to explore
algorithmic problem-solving, game logic, and search-based reasoning.

## Projects

### Connect 4
- Console-based two-player implementation
- Win detection across rows, columns, and diagonals
- Simulated coin-drop animation using time delays

## N-Queens

Comparative study of three constraint-solving algorithms on the N-Queens problem.

**Algorithms implemented:**
- Backtracking — exhaustive recursive search
- Forward Checking — backtracking with constraint propagation  
- Minimum Conflicts — local search heuristic (averaged over 100 trials)

**[Live Visualizer →](https://rachitagrawal146.github.io/game-algorithms-java/Visualizer/NQueensVisualizer.html)**

### 21-Card Trick
- Deterministic card-guessing algorithm
- Uses array rearrangement and user interaction
- Demonstrates how structure can replace randomness

### Mastermind / Code Breaker
- Code generation without repetition
- Guess evaluation using exact and partial matches
- Console-based visual board output
